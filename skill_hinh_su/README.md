# Bộ Skill thống kê án hình sự

Gói này gồm:

- `SKILL_HINH_SU.md`: file skill chính.
- `criminal_formula_catalog.json`: catalog công thức cho Mẫu 1A, 1B, 1C, 1D.
- `criminal_data_dictionary.json`: từ điển cột đọc từ 04 file Excel biểu mẫu hình sự.

Nguồn xây dựng: file hướng dẫn biểu mẫu thống kê TANDTC và 04 biểu mẫu Excel hình sự do người dùng cung cấp.
