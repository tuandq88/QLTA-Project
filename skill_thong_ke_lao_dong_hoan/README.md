# Bộ Skill thống kê án Lao động hoàn chỉnh

Bộ này được tạo từ 04 biểu mẫu Excel người dùng cung cấp:
- Lao động sơ thẩm.xlsx
- Lao động phúc thẩm.xlsx
- Lao động giám đốc thẩm.xlsx
- Lao động tái thẩm.xlsx

Các tệp chính:
- SKILL.md: hướng dẫn vận hành skill
- formula_catalog_lao_dong.json: danh mục công thức
- validation_rules_lao_dong.json: quy tắc kiểm tra số liệu
- column_mapping_lao_dong.json: ánh xạ từng cột biểu mẫu
- data_dictionary_lao_dong.json: từ điển dữ liệu đầu vào
- input_mapping_lao_dong.json: phân loại dữ liệu nhập tay/tự động/tính toán
