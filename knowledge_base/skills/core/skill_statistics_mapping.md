# Statistics Mapping tổng

## Công thức chung
Tồn cuối kỳ = Tồn đầu kỳ + Thụ lý trong kỳ - Giải quyết trong kỳ.

## Dimensions
- court_unit
- case_type
- dispute/offense/object_type
- judge
- month, quarter, year
- status

## Metrics
- received_count
- accepted_count
- resolved_count
- pending_count
- overdue_count
- appealed_count
- cancelled_modified_count
